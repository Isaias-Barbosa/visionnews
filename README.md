# VisionNews

Portal editorial de animes em português brasileiro.

Notícias, reviews, guias, calendário, trilhas de leitura e favoritos locais.

Os arquivos em `public/` compõem a primeira versão estática. A área administrativa será adicionada no próximo passo.

Conteúdo demonstrativo e grade em apuração são identificados na interface. Imagens promocionais de terceiros são referenciadas externamente e precisam de revisão de direitos antes do lançamento comercial.
